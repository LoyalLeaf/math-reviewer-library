# Math Sprint Library

An offline-first mathematics reviewer website for Grades 7 to 10.

## Included

- Concise topic cards for Grades 7–9 foundations and the Math 10 session set.
- Formula sheet for financial math, coordinate geometry, linear models, quadratics, and circles.
- A built-in 10-question quiz sprint with scoring and explanations.
- No API key, network request, framework, or build step required.

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Source materials

The topic map was condensed from the local `Downloads/Math 10` reviewer pack, including:

- `Reviewers/Grade 7-9 Reviewer.pdf`
- `Reviewers/Overall Reviewer.pdf`
- `G10 Sessions/Session 1` through `Session 15`

The site is a study companion, not a replacement for the full source files.
